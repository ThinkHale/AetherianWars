## Modeling handoff

Use the linked selected versions above; earlier versions are retained for traceability. Neutral grey backgrounds are intentional modeling-reference backdrops, not transparent sprite assets. Some sheets include separate equipment details; the three full-body figures are the primary references. Mounted scenes are supplementary only.

These are raster visual guides, not rigged meshes or calibrated CAD orthographics. Reconcile fine embroidery, straps, accessory handedness and hidden anatomy while building one consistent model; the written profiles establish the intended equipment conventions. Long robes and cloaks intentionally conceal some anatomy and should be modeled over a standard anatomical base. Do not infer underlying topology from the paintings. The PNGs do not add playable fighters to the running game.

`manifest.json` records selected files, dimensions, hashes and prompt paths. Prompts for refined sheets refer to the earlier same-hero sheet, which remains alongside them. Source likeness portraits remain in `../references/`.
