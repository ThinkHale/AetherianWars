# Art inbox

Put ChatGPT output here, laid out as docs/chatgpt-art-brief.md lists:

    fighters/<hero>/<action>.png
    stages/<stage>-far.png, -mid.png, -floor.png
    icon.png
    key-art.png

Then run `swift Tools/import-art.swift` from the repo root. Images here are
not committed; what the importer produces in App/Resources is.
